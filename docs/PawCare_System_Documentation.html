1. Dashboard Overview & Patient Management Interface

The PawCare dashboard provides a central command center for veterinary clinics to manage patient intake, monitor appointments, schedule consultations, and maintain real-time operational statistics.

Figure 1.1: Live PawCare Clinic Dashboard running at http://localhost with real-time statistics cards, appointment directory table, status badges, and action controls.

Dashboard Core Features:

  • Real-Time Metrics: Displays Total, Scheduled, Completed, and Cancelled patient counts calculated atomically from SQLite.
  • Live Instant Search: Debounced multi-field searching across pet name, breed/species, owner name, phone, and service.
  • One-Click Status Editing: Inline interactive status selection (Scheduled, Completed, Cancelled) with immediate persistence.
  • Breed-Aware Avatars: Automatic visual matching of patient avatars for dogs, cats, rabbits, birds, and other animals.

2. System Architecture & Topology

PawCare operates with strict separation of concerns, housing the WSGI application and the reverse proxy in dedicated, isolated Docker containers: 

[ Client Browser ] --- (Port 80) ---> [ pawcare_nginx (Nginx 1.31) ]
                                             |
                                             v (Reverse Proxy: http://web:5000)
                                      [ pawcare_web (Gunicorn + Flask) ]
                                             |
                                             v (Atomic Read / Write: WAL Mode)
                                      [ pawcare_db_data Volume (SQLite) ]

6. Operational Commands Summary

Operation Terminal Command Description

Check Status docker compose ps Lists container states, health status, and port bindings.

Stop Stack docker compose down Stops containers while preserving persistent SQLite volume data.
