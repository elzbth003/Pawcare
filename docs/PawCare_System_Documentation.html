2. System Architecture & Topology

PawCare operates with strict separation of concerns, housing the WSGI application and the reverse proxy in dedicated, isolated Docker containers: 

[ Client Browser ] --- (Port 80) ---> [ pawcare_nginx (Nginx 1.31) ]
                                             |
                                             v (Reverse Proxy: http://web:5000)
                                      [ pawcare_web (Gunicorn + Flask) ]
                                             |
                                             v (Atomic Read / Write: WAL Mode)
                                      [ pawcare_db_data Volume (SQLite) ]

6. Operational Commands Summary

Operation Terminal Command Description
Start Stack docker compose up --build -d Builds images and boots web and nginx services in background.
Check Status docker compose ps Lists container states, health status, and port bindings.
View Web Logs docker compose logs -f web Follows live Gunicorn WSGI output and request handling.

Stop Stack docker compose down Stops containers while preserving persistent SQLite volume data.
